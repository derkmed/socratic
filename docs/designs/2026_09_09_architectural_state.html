The whole system

Two containers, one browser, one offline job. The figure carries the shape only — who talks to whom, and which way. What each box holds is set out under Reading the figure, because a diagram that states everything states nothing legibly.

Reading the figure

Two paths to the service, two credentials

The Pipe reaches the service by its compose DNS name with the shared SOCRATIC_SERVICE_TOKEN. The iframe reaches it from the learner’s browser at SOCRATIC_PUBLIC_URL with an HMAC capability token scoped to one QuizSessionId and its LearnerId, short TTL, re-minted on every grading response. It needs its own credential because a sandboxed srcdoc frame has an opaque origin and cannot authenticate by any ambient means. ServiceDependencies holds the two as separate fields so no handler can accept either.

The overlay is emitted, not returned

The Pipe awaits __event_emitter__ with an embeds event (ADR-0017). A Pipe that returns it renders nothing at all, silently.

What the boxes hold

  • FastAPI routes — seven: /quizzes, /overlays, /answers, /probes, /settings, /displacements, /ratings.
  • QuizAuthoring — mints the ULID QuizSessionId, then two model calls: skeleton, then pedagogy.
  • QuizSession — grading, the three-rung hint ladder, probe cadence, sealing. Its model calls are dashed because only Advanced makes them: Novice feedback is wholly pre-authored, so a Novice answer costs zero model calls.
  • ModeRegistry — the one place mode is branched on. Holds the per-mode policy, including the blank range: Novice 1–2, Advanced 4–6. An if mode == anywhere else is a bug.
  • prompting — three segments. Segment 1 is invariant and cached, one prefix per call type; segment 2 is the learner profile and the quiz; the volatile tail is never cached. Five call types means five separate prefixes.
  • Repositories — attempts, ratings, settings, profiles. The answer key lives here and is never serialized into the iframe.
  • Anthropic API — claude-opus-5, effort low, set by an admin Valve rather than per learner, because caches are model-scoped.

Dashed also means decided but not built. adapters/ holds only anthropic_client.py today; the on-disk record writer of ADR-0018 and the ProfileBuilder wiring are not in the running service, and the profile repository is not reachable from it at all. Storage is in memory, so a restart loses every in-flight quiz.
